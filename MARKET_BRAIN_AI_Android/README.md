# MARKET BRAIN AI — Android (base 0.1.0)

Este é o projeto-fonte inicial de um aplicativo Android nativo com painel local em WebView.

## Estado atual
- Aplicativo Android estrutural.
- Painel visual em português.
- Modo demonstrativo claramente identificado.
- Sem conexão com cotações ao vivo.
- Sem geração de sinais reais.
- Sem login, credenciais ou execução de ordens.

## Como gerar o APK
1. Instale o Android Studio em um computador.
2. Abra a pasta `MARKET_BRAIN_AI_Android` no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Se solicitado, instale Android SDK Platform 35 e Build Tools compatíveis.
5. Use **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. O Android Studio informará o caminho do APK gerado.
